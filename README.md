# Book Recommendation System

A simple content-based book recommendation web app built with **Python** and **Streamlit**. Users select a book from a dropdown menu and click **Recommend** to see five similar book titles.

## Features

- Select a book from the available book titles.
- Generate recommendations using a precomputed similarity matrix.
- Display the top five recommendations for the selected book.
- Lightweight web interface powered by Streamlit.

## How It Works

The app loads two prepared files:

- `books.pickle` — a serialized data object containing book information. The app expects a `title` column.
- `similarities.joblib` — a saved similarity matrix used to find books similar to the selected title.

When a user clicks **Recommend**, the app:

1. Finds the selected book's row in the `books` data.
2. Reads that row's similarity scores from the similarity matrix.
3. Sorts the scores from highest to lowest.
4. Skips the first result (normally the selected book itself).
5. Displays the next five book titles.

## Project Structure

Keep the following files in the same directory:

```text
book-recommendation-app/
├── app.py
├── books.pickle
├── similarities.joblib
└── README.md
```

The two data/model files are required at runtime. They are not generated by `app.py`.

## Requirements

- Python 3.9 or a compatible Python version
- Streamlit
- joblib
- pandas (needed for the table loaded from the pickle file)

The app also imports `regex`, but the current code does not use it. Python's built-in `pickle` module is included with Python.

## Installation

### 1. Clone or download the project

If this project is on GitHub:

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_REPOSITORY_FOLDER>
```

Or download the project files and open a terminal in the project directory.

### 2. Create and activate a virtual environment (recommended)

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS/Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install streamlit pandas joblib regex
```

### 4. Add the required data files

Ensure these files are next to `app.py`:

- `books.pickle`
- `similarities.joblib`

If they are missing, the app cannot load the book data or similarity matrix.

## Run the App

From the project directory, run:

```bash
streamlit run app.py
```

Streamlit will print a local URL (usually `http://localhost:8501`). Open that URL in your browser.
